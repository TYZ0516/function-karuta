遊戲內容

畫面上方出現一個函數，下方有 6 張圖形牌，學生要搶到正確的那一張。其他 5 張是「干擾牌」，大多只和正解差一個特徵（例如只有頂點左右相反），逼學生一項一項檢查，不能只看大概的形狀。

關卡函數形式要判斷的特徵
第 1 關y = ax + b斜率正負、陡或緩（以 y = ±x 虛線為基準）、y 截距
第 2 關y = a(x − h)² + k開口方向、頂點（特別是 h 的正負號）
第 3 關y = ax² + bx + c開口方向、y 截距 c、對稱軸 x = −b/2a
第 4 關y = a(x − h)³ + k走向、對稱中心
第 5 關y = a(x − h)³ + p(x − h) + k走向、峰谷（a、p 異號才有峰谷）、對稱中心
綜合五關隨機混合—

學生搶錯時，系統會說明錯在哪裡，例如「這張是『頂點 x = 2』，題目是『頂點 x = −2』」。一局結束後，會統計每個人「判斷錯最多的特徵」。

操作：輕點牌＝搶牌；長按牌＝放大看清楚（放開不算搶）。

四種模式

模式網路適合
單人挑戰電腦不用自主練習。電腦有烏龜／兔子／獵豹三種速度；二次一般式要配方，電腦會多給一倍時間。
同機雙人不用手機平放桌上，上下各一半，兩人面對面搶。沒有網路的教室也能玩。
線上 1 對 1要一人開房間，拿到 4 位數代碼給對手輸入。依伺服器時間判定誰先搶到。
全班搶牌要老師用電腦投影開房，全班同時搶，有即時排行榜，類似 Kahoot。

全班搶牌上課流程

  1. 電腦接投影機，打開網站 → 選關卡 →「全班搶牌」。需要的話，可以先打開「作答時間寬鬆 ×1.5」。
  2. 投影幕出現房間代碼和 QR code。學生用手機相機掃描，輸入暱稱加入。請提醒學生不要輸入真實全名。
  3. 暱稱最多 8 個字。如果有人取了不當的暱稱，在投影幕上點他的名字，會跳出選單：
    ✏️ 請改名：他的手機會跳到改名畫面，換好名字就回到房間，分數保留。
    🚫 移出：這個房間他就進不來了（同一支手機的同一個瀏覽器）。
  4. 按「開始」。每題作答時間：一次 20 秒、二次標準式 30 秒、二次一般式 60 秒、三次基本 30 秒、三次魔王 45 秒。全部的人都作答，或時間到，就會公布答案；也可以按「提早結束這題」。
  5. 每人每題只能搶一次，作答時不顯示對錯。答對的人依速度得 500～1000 分，全班最快答對的再加 100 分。
  6. 公布答案時，投影幕會顯示每張牌各有幾個人選，以及最多人錯選的那張錯在哪裡，可以當場講解。
  7. 10 題結束後，顯示前三名、完整排名，以及全班最常判斷錯的地方。按「關閉房間」會刪除這個房間的資料。

教學建議

  • 先用「單人挑戰電腦」的烏龜速度熟悉操作，再進到對戰。
  • 首頁的「判斷步驟提示」會在題目下方列出要看哪些特徵（例如「① a 的正負 → 開口　② 頂點 (h, k)」），對程度較弱的學生很有幫助。熟練後可以關掉。
  • 一次函數的 y = ±x 虛線，是讓學生判斷陡或緩的基準，熟練後也可以關掉。
  • 公布答案時，「最多人錯選」的那張牌最值得講，通常就是全班共同的迷思（例如 x − h 的正負號）。
  • 最後的「全班最常判斷錯的地方」可以拍照留存，作為下一堂課的複習重點。

常見問題

學生要註冊帳號嗎？會蒐集個資嗎？

不用註冊。系統用匿名登入，只存學生自己輸入的暱稱和作答紀錄，關閉房間後就會刪除。

學生連不進來？

有些校園網路會擋即時連線服務，請在教室先用學校 Wi-Fi 測試；被擋的話，可以改用手機熱點。如果用 LINE 掃 QR code，網頁會開在 LINE 裡面，請改用「以預設瀏覽器開啟」。

同時有好幾個班在用，會不會塞爆？

這個網站用的是 Firebase 免費方案，整個網站同時最多 100 個連線，所有使用的老師共用。一兩個班同時使用沒問題，三個班以上同時開全班搶牌，後面加入的學生就會連不上。

如果你的學校要經常在課堂上使用，建議照下面的步驟自己架一份，用量就是你們學校自己的，大約 20 分鐘可以完成，也是免費的。

怎麼加到手機主畫面？

Android（Chrome）：右上角 ⋮ →「加到主畫面」或「安裝應用程式」。iPhone（Safari）：下方分享鈕 →「加入主畫面」。之後打開就是全螢幕。

沒有網路可以玩嗎？

單人挑戰電腦和同機雙人只要網頁載入過就能玩，不需要連線。

外校老師：自己架一份

需要：一個 Google 帳號（建 Firebase）和一個 GitHub 帳號（放網頁），都免費。

  1. 到 GitHub 原始碼頁面 點右上角「Fork」複製一份到自己的帳號；或點綠色「Code → Download ZIP」下載所有檔案。
  2. 照原始碼頁面上的 README 操作：建立 Firebase 專案 → 開啟匿名登入 → 建立 Realtime Database（地區選 asia-southeast1）→ 貼上 database.rules.json 的安全規則 → 把自己的設定碼貼進 config.js。
  3. 在自己的 repository 開啟 GitHub Pages（Settings → Pages → main / root）。
  4. 回 Firebase，把 你的帳號.github.io 加進 Authentication 的「授權網域」。

完成後就有一個你們學校自己的網址，用量和資料都和這個網站分開。架設時遇到問題，歡迎來信詢問。
